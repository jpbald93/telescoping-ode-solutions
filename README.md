# Telescoping ODE solutions — reproduction package

Reproduction and verification package for the note

> **Telescoping Solutions of Differential Equations: A High-Order Exponential
> Approximation Framework**, Josh Bald.

The paper replaces the exponentials in the closed-form solutions of linear ODEs by
*telescoping exponential approximants* (the **c-in-base** parametrisation, which
differs from the author's functions paper)

```
E_n^(s)(c) = (1 + c/n + s·√3·c²/(6 n²))^(n + c(1/2 − s·√3/6)),   s = ±1,
```

whose successive differences decay as `O(n^-4)`, and lifts this to first-order
ODEs `y' = a y`, the harmonic oscillator `y'' + ω² y = 0`, and matrix systems
`x' = A x`, with a general theorem covering any constant-coefficient linear ODE
whose solution is a finite combination of `t^j e^{λt}`.

Key quantities (all regenerated by `code/verify_ode.py`):

```
log E_n^(s)(c) − c = g₃^(s)(c) n^-3 + O(n^-4),   g₃^(s)(c) = c⁴(−3 + 2 s√3)/72,
E_{n+1}^(s)(c) − E_n^(s)(c) = −3 g₃^(s)(c) e^c n^-4 + O(n^-5)
                            = c⁴(3 − 2 s√3)/24 · e^c · n^-4 + O(n^-5),
|E_n^(s)(i x)|² = 1 + O(n^-3),      ∂_c log E_n^(s) = 1 + O(n^-3).
```

This package lets a referee regenerate every numeral in the paper and re-check
every kernel-verified algebraic identity from a clean checkout.

## Evidence tiers

The paper labels every quantitative claim:

- **[Lean]** — kernel-checked in `lean/` (the exact algebra): the log-series
  coefficient identities `u1_coeff_zero` (`A₁ = 0`), `u2_coeff_zero`
  (`A₂ = 0` given `(s√3)² = 3`), `u3_coeff_eq_g3` (`A₃ = g₃`); the
  finite-difference factor `−3` (`diff_cube_factor`); the leading-constant
  identity `−3 g₃ = c⁴(3 − 2s√3)/24` (`lead_eq`) and positivity of the `s = −1`
  branch constant (`leadMinus_pos`); the derivative-cancellation vanishings
  (`deriv_u1_plus/minus`); and the Pythagorean base identity (`pyth_expand`).
- **[num]** — confirmed by high-precision computation, **not** proved: the
  asymptotic expansions themselves, the `O(n^-4)` difference decay, the
  non-normal matrix convergence, and the `g₄`, `g₅` coefficients.
  `code/verify_ode.py` recovers the leading constants by a Neville tableau and
  checks the matrix rates at arbitrary precision.
- **[classical]** — standard facts (existence of the analytic logarithm near
  `u = 0`, uniform convergence on compact sets, the structure of solutions of
  constant-coefficient linear ODEs).

The `O(·)` asymptotic statements are **not** formalised in Lean.

## Reproduce the numerics

Requires Python 3 with `mpmath` and `sympy`.

```bash
python3 code/verify_ode.py 100      # optional precision argument (digits)
```

This prints, and `code/verify_output.txt` records:

1. **Symbolic** (SymPy) coefficients `u¹..u⁵` of `log E_n^(s) − c`: `u¹ = u² = 0`,
   `u³ = g₃ = c⁴(−3 + 2s√3)/72`, plus `g₄`, `g₅`; and the derivative coefficients
   (`u⁰ = 1`, `u¹ = u² = 0`, so the derivative preserves order 3); and the
   Pythagorean base polynomial.
2. **High-precision** confirmation of the leading difference constant
   `lim n⁴ Dₙ = c⁴(3 − 2s√3)/24 · e^c` by a Neville tableau.
3. The **matrix engine** on a non-normal `3×3` matrix at high precision:
   `n³‖M_n − e^{At}‖_op → 0.0011759…` and `n⁴‖M_{n+1} − M_n‖_op → 0.0035277…`.
4. The **derivative-order check**: `n³·(d/dt E_n(ωt) − ω e^{ωt}) →` nonzero
   constant, i.e. the `n^-3` order is *preserved* under differentiation.

## Verify the Lean development

Requires `elan`/`lake` with the toolchain pinned in `lean/lean-toolchain`
(`leanprover/lean4:v4.33.1`).

```bash
cd lean
lake exe cache get          # fetch the Mathlib build cache (do not skip)
./gate.sh
```

`gate.sh` requires: a successful build; no `sorry`/`admit`/`axiom`/
`native_decide`; only the three standard axioms (`propext`, `Classical.choice`,
`Quot.sound`); and a minimum count of audited theorems (negative-tested). Expected
output:

```
PASS (12 theorems, standard axioms only)
```

`scratch/Satisfiable.lean` gives, for every theorem with hypotheses, a Lean-checked example showing the hypotheses can all be met (compile with `lake env lean scratch/Satisfiable.lean`).

The Lean sources are shipped source-only; the `.lake` build directory is
git-ignored and regenerated by `lake exe cache get` + `lake build`.

## Provenance

This note was developed from the author's earlier draft. The corrected version
fixes a matrix proof that was previously only asserted, an invalid
complex-modulus step in the Pythagorean argument, an over-normalised constant in
the error corollary, and a claim (carried from a different approximant) that
cosine at `x = π` degenerates to order six — which is false for this
parametrisation. The exact algebra was derived symbolically, confirmed
numerically to high precision, and kernel-checked in Lean. The manuscript was
drafted with a large-language-model assistant under the author's direction and
independently audited by two separate systems; see `reports/`.
