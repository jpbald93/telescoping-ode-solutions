=== PART 1b: derivative cancellation d/dc log E_n = 1 + O(n^-3) ===
    (+): u^0 = 1, u^1 = 0, u^2 = 0
    (-): u^0 = 1, u^1 = 0, u^2 = 0
  -> u^0 = 1, u^1 = 0, u^2 = 0: BOTH lower terms vanish, so the derivative
     preserves the n^-3 order (NOT an order drop).
